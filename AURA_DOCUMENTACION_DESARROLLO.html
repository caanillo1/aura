Arquitectura General

AURA ERP es un sistema monorepo con arquitectura cliente-servidor desacoplada. El backend expone una API REST + WebSockets y el frontend consume la API vía HTTP y sockets en tiempo real.

Backend — Tecnologías y Patrones

Estructura del proyecto

apps/backend/src/
├── modules/ — Módulos NestJS por dominio
├── common/ — Guards, decoradores, pipes
├── prisma/ — Servicio Prisma singleton
└── main.ts — Bootstrap, CORS, Swagger

Convenciones clave

• Puerto: 3001
• IDs: UUID v4 (UniqueIdentifier en SQL Server)
• Fechas: DateTime2 (UTC)
• Auth header: Bearer <JWT>
• Multi-tenant: companyId en cada query

Base de Datos — Resumen

Motor: Microsoft SQL Server 2016
ORM: Prisma 5.22 (provider: sqlserver)
Conexión: Variable DATABASE_URL
PKs: UUID v4 (tipo UniqueIdentifier)
Fechas: DateTime2 en UTC
Textos largos: NVarChar(Max)
Total de tablas: 47
Multi-tenant: companyId en 25+ tablas
Tablas pivot: 5 con PK compuesta
Soft-delete: campo isActive en entidades principales
Auditoría: tabla RegistroAuditoria con PK autoincrement
Prefijo: Nombres en español (@@map)
Nota sobre nombres de tabla: El schema usa @@map() para mapear modelos en inglés a nombres de tabla en español. Por ejemplo: Company → tabla Empresas. Esto evita palabras reservadas de SQL Server.
